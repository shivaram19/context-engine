## Ways to Contribute

We welcome:
- **Code** — Features, bug fixes, optimization
- **Testing** — RLS safety, multilingual edge cases, real data validation
- **Documentation** — Guides, examples, translations
- **Design** — UI/UX, dashboard layouts
- **Connectors** — New data sources (Notion, Slack, Jira, etc.)
- **Languages** — Hindi, Tamil, Marathi, Bengali support and benchmarking
- **Feedback** — Feature requests, usability findings

See `CONTRIBUTING.md` for guidelines.

## How We Work Together

- **Respect** — Code review is constructive feedback, not gatekeeping
- **Transparency** — Roadmap is public (`VISION.md`), decisions are documented
- **Speed** — We ship fast; perfectionism is deferred to Phase 2+
- **Community** — We celebrate shipping, not just writing code
